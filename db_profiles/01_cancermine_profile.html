🔵 CancerMine

Literature-mined knowledgebase — 38,204 gene–cancer–role triples across 538 cancer types

CancerMine was built by running the Kindred NLP framework across PubMed and PMC full-text articles. It identifies sentences where a gene is described as a driver, oncogene, or tumor suppressor in a specific cancer, then aggregates evidence by counting independent citations per triple. Each row = one unique (gene × cancer × role) combination, weighted by citation count.

🔬 Column-by-Column Explanation
matching_id
string
Unique row ID linking this triple to supporting sentences. Format: Role_DiseaseOntologyID_EnsemblID.
Example: Driver_DOID:1612_ENSG00000141510
Used for: Join key to cancermine_sentences.tsv for evidence retrieval
role
enum
The gene's functional role in this cancer: Driver = frequently mutated to promote cancer; Oncogene = promotes cell growth when activated; Tumor_Suppressor = protects against cancer when normally functioning.
Example: Driver | Oncogene | Tumor_Suppressor
Used for: Primary KG edge type; ML classification target
cancer_id
string
Disease Ontology (DO) identifier for the cancer. Standardised ID enabling cross-database linking.
Example: DOID:1612 (breast cancer)
Used for: Linking to HeNeCOn ontology and external disease databases
cancer_normalized
string
Normalised, human-readable cancer type name from the NLP pipeline.
Example: breast cancer
Used for: Cancer node label in KG; grouping by cancer type
gene_hugo_id
integer
HUGO Gene Nomenclature Committee numeric ID — the official human gene naming authority.
Example: 11998
Used for: Cross-referencing with HGNC databases
gene_entrez_id
integer
NCBI Entrez Gene ID — the universal gene ID used by PubMed, COSMIC, and UniProt.
Example: 7157 (TP53)
Used for: Linking CancerMine to COSMIC via shared Entrez IDs
gene_normalized
string
Official HUGO gene symbol — standardised short gene name used in all genomics publications.
Example: TP53
Used for: Gene node label in KG; primary join key with COSMIC GENE_SYMBOL column
citation_count
integer
Number of distinct PubMed/PMC papers supporting this gene-cancer-role triple. Higher = stronger evidence. Log10-normalised per cancer type to produce the KG edge weight.
Example: 1842
Used for: KG edge weight; importance score; confidence filter

import pandas as pd, numpy as np cm = pd.read_csv("cancermine/cancermine_collated.tsv", sep="\t") print(cm.shape) # (38204, 9) print(cm.dtypes) # Role distribution print(cm["role"].value_counts()) # Top driver genes for head & neck cancer hnc = cm[cm["cancer_normalized"].str.contains("head and neck", case=False)] print(hnc[hnc["role"]=="Driver"] .sort_values("citation_count", ascending=False) [["gene_normalized","cancer_normalized","citation_count"]].head(10)) # Normalised importance score (KG edge weight) cm["importance"] = np.log10(cm["citation_count"] + 1) mx = cm.groupby("cancer_normalized")["importance"].transform("max") cm["score"] = (cm["importance"] / (mx + 1e-9)).round(4) # Context-dependent genes (e.g. NOTCH1 = oncogene in T-ALL, suppressor in HNC) multi = cm.groupby("gene_normalized")["role"].nunique() print("Genes with >1 role:", (multi > 1).sum())
