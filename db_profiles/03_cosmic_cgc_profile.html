🟢 COSMIC MutantCensus — Cancer Gene Census (CGC)

Gold-standard cancer driver genes with Tier 1/2 confidence scoring — v103, GRCh37

The MutantCensus is restricted to the 723 Cancer Gene Census (CGC) genes — those with the strongest evidence of causal cancer involvement. Tier 1 genes have definitive evidence: known gain-of-function (oncogene) or loss-of-function (tumour suppressor) mutations proven to drive cancer. This is the gold-standard reference set for cancer gene ML models and clinical genomics.

🔬 Column-by-Column Explanation
GENE_SYMBOL
string
HGNC gene symbol — all CGC genes are causally implicated in cancer.
Example: TP53
Used for: Primary join key; all genes here are known cancer drivers
PRIMARY_SITE
string
Tissue/organ of tumour origin. Same COSMIC vocabulary as CMC.
Example: lung
Used for: Tissue node in KG
HISTOLOGY
string
Histological tumour type — more specific than primary site.
Example: carcinoma
Used for: Subtype-level tissue classification
MUTATION_DESCRIPTION
string
Molecular consequence: Missense, Nonsense, Frameshift, Splice site, etc.
Example: Missense
Used for: Mutation type ML feature
MUTATION_SOMATIC_STATUS
string
Confirms the mutation is somatic (not germline). Key quality filter for cancer ML models.
Example: Confirmed somatic variant
Used for: Somatic filter — remove germline variants that are not cancer mutations
TIER
integer
CGC confidence: Tier 1 = strongest direct causal evidence; Tier 2 = indirect evidence. Tier 1 genes are the gold-standard cancer driver set.
Example: 1
Used for: Confidence filter — Tier 1 = gold standard
GENOMIC_MUTATION_ID
string
Stable COSV identifier across COSMIC releases.
Example: COSV51765119
Used for: Mutation node ID in KG
MUTATION_CDS
string
HGVS coding DNA change.
Example: c.817C>T
Used for: Exact nucleotide change
MUTATION_AA
string
HGVS amino acid change.
Example: p.R273C
Used for: Protein consequence
SAMPLE_ID
string
Tumour sample identifier.
Example: TCGA-A1-A0SB-01A
Used for: Sample-level aggregation
